# 系统设计

[首页](../README.zh-CN.md) · [English](architecture.md)

当前网站由 Python 编排客服流程，使用 SQLite 保存业务状态，JavaScript 展示界面。模型不具备任意选择和执行数据库写入的权限。

```text
客户消息＋近期公开对话
  → 主题识别与分诊
  → 查询该客户的业务数据＋检索知识
  → 基于当前证据生成答复
  → 内容与操作检查
  → 自动回复、澄清、内部建议或转人工
  → 保存状态 → SSE 通知 → 各端按权限获取最新数据
```

## 证据与操作

10 个只读工具覆盖账户概览、订阅、订单、发票、近期请求、平台状态、API Key 元数据、工单历史、余额回正资格和知识检索。查询范围绑定工单所属客户。

模型输出结构化判断及措辞，Python 控制查询、事实检查和发送。业务写入经过应用服务和角色校验：客服可回复、撤回、执行当前工单的 `/recharge` 及不改金额的发票修改 / 重开；符合条件的回正可经程序核验后自动执行；管理员另可审批退款、调整发票金额，以及管理账户、套餐、任意余额和全局 AI 开关。金额变动均为本地模拟。

额度刷新属于应用维护，在收集证据及模拟调用前执行，不赋予查询工具或模型写权限。每条消息保存客户的事件时区，由 Python 解析请求编号及 UTC 区间，并把相同证据交给生成与质检。[业务规则](business-rules.zh-CN.md)。

## 知识与检索

网站初始化使用 `support_agent/desk/data/knowledge.json` 中的 **10 条合成规则**。每条保留完整规则或 FAQ、独立 ID 与元数据，属于人工组织的语义单元，不是固定字数切块。

另有早期 RAG 的 **19 条合成知识**。其 PDF 导入按编号三级标题组织，FAQ 保留完整条目；该导入流程不会自动替换当前网站知识表。[知识范围说明](../knowledge/README.zh-CN.md)。

共用检索器组合归一化 BM25（**0.62**）和字符二元 / 三元计数的余弦相似度（**0.38**）。BM25 使用 `k1=1.5`、`b=0.75`，特征包含中文单字、双字组合及英文标识。字符相似度是词面匹配，没有使用 Embedding 模型。

v0.5.9 排序后按当前主题、完整错误码及知识能力范围筛选，最多保留 **4 条**。10 个内置规则 ID 使用业务词规则；自定义已发布 FAQ 要求覆盖度 ≥ 0.55。这是小领域过滤，不能当作通用语义理解。静态规则、实时查询和知识缺失分别处理；旧覆盖度 ≥ 0.12 的实验继续保留。[评测](evaluation.zh-CN.md)。

## 上下文与人工协作

- 模型最多读取此前 **24 条公开消息**，约 **16,000 字符**，包含客户、AI 和人工回复；截断时有标记。
- 撤回正文、内部建议、内部备注和其他客户的对话不进入模型上下文。
- 主题跟踪区分当前与暂停的问题；切回旧问题时重新查询业务状态，指代不清时允许澄清。
- 人工回复后优先 **15 分钟**；客户追问 **60 秒**无人回复才生成内部建议。主动接管持续到客服点击“恢复 AI”。
- 新消息使旧待发建议失效；自动发送仍受全局开关、工单状态、内容及业务操作检查限制。

## 模型接入

本地模式使用规则和模板。可选接入 Chat Completions 或 Responses，依次执行分诊、生成、质检，通常 **3 次调用**；一次内容修订最多再增加 **2 次调用**。生成和质检获得同一份当前证据与对话上下文。

同次结构化回复先生成 `evidence_summary` 再生成 `answer`；程序补充真实执行记录并在最终回复前保存管理员专属消息。API 过滤私有内容，客服只接收最终草稿与操作按钮；内部消息不进入后续公开对话上下文。

启动先检查三个阶段；运行时区分接口失败、内容拒绝与本地回退，保留模型名称及脱敏原因。项目未进行模型权重训练。

## 模块分工

| 路径 | 职责 |
|---|---|
| `support_agent/portal.py` | HTTP、登录会话、权限和 SSE |
| `support_agent/desk/service.py` | 工单、后台生成、人工优先与发送 |
| `support_agent/desk/engine.py` | 分诊、证据编排和回复检查 |
| `support_agent/desk/billing.py` | 到期刷新、过期处理和额度账本 |
| `support_agent/desk/request_context.py` | 账户范围内请求定位、时区证据及歧义处理 |
| `support_agent/desk/sandbox.py` | 模拟用量与事务扣款 |
| `support_agent/desk/topics.py` | 当前主题与追问处理 |
| `support_agent/desk/tools.py` | 客户范围内的只读查询 |
| `support_agent/desk/knowledge.py` | 主题、能力与完整标识过滤 |
| `support_agent/desk/audit.py` | 管理员依据及用量费用汇总 |
| `support_agent/desk/model.py` | 模型提示、生成和质检 |
| `support_agent/desk/storage.py` | SQLite 表、迁移与合成数据 |
| `support_agent/desk/admin.py` | 账号、套餐、余额和知识管理 |
| `support_agent/retrieval.py` | 共用 BM25 与字符相似度 |
| `support_agent/desk/static/` | 网站界面及实时同步 |

[早期 RAG 架构](legacy/architecture.zh-CN.md)描述的是独立聊天入口，不是当前业务网站。
