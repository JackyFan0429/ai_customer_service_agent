[English](reviewed-changes.md) · [业务规则](business-rules.zh-CN.md)

基于 v0.5.8 新建独立项目，旧项目和运行中的数据库保持不变。

| 已确认事项 | 本次实现 | 验证 |
|---|---|---|
| RET-029、030 通过 | v3 的 30 题全部确认 | 严格标签校验 |
| 区分政策咨询、业务事实和知识缺失 | 主题 / 能力过滤，不编造模型规格，不把 1401 当 401 | 已复核检索题和流程检查 |
| AI 可自动回正 | 明确诉求、来源账本核验、$5 / 7 天规则、提交前复核 | 资格、幂等与回滚测试 |
| 客服 / 管理员 `/recharge` | 仅当前工单客户的负余额归零，结果仅内部显示 | 角色及公开消息隔离检查 |
| 依据说明仅管理员可见 | 同次结构化摘要＋真实执行记录，在最终回复前保存；接口过滤 | 模拟模型、权限及页面验收 |
| 人工协作保留 | 15 分钟人工优先，60 秒延迟草稿，最终草稿可编辑发送和撤回 | 流程与双端实时检查 |
| 汇总模型用量费用 | Token、重试、失败、自填单价；缺失信息不算零成本 | 统计测试及管理页面 |

v0.5.8 已有的额度定时刷新、模拟扣余额、请求编号 / 时区、发票修改及管理员退款审批继续保留。本轮未连接真实支付，也未调用真实模型 API。

后续需测：新未见检索题、新输出结构下的真实模型表现，以及实际人工处理时长、建议采纳率、每张解决工单成本。已有题的成绩不代表普遍回答准确率或收益。
