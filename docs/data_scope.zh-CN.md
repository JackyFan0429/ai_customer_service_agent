# 数据与匿名化边界

[English](data_scope.md) | **简体中文**

项目名称为“智能客服 Agent 与知识库治理”，定位为面向 AI API 平台的个人客服原型，尚未接入真实客服，不代表任何公司的官方产品。

## 公开文件

- `support_agent/demo/corpus.jsonl`：19 条合成资料，客户端和模型名称均为虚构标签，`.example` 地址不连接真实服务。P1/P2 只模拟证据优先级，远期日期只用于稳定演示。
- `evals/scenarios.jsonl`：48 个合成开发场景、63 轮消息。版本为 `synthetic-v2-neutral`，AI 编写的标签仍待项目本人复核。
- `evals/results/`：匿名化后重新运行的改前、改后逐项报告，保留本次资料、评分器、实现文件的哈希。
- `evals/baselines/pre_iteration.patch`：将当前核心实现还原为匿名化后的改前逻辑，用于重现已知问题；原始带品牌版本没有放入补丁。

## 私有历史资料

原始工单、内部知识、公开网站摘录、来源复核日志、派生产物和旧演示数据库不再包含在项目目录及公开压缩包中。原件由项目本人另行归档，保留真实来源和审计记录，不用虚构网址替换原始证据。

简历与面试中提到的 1,659 条历史案例、660 条归档或待复核记录、1,086 条检索记录，描述的是既往私有快照的处理规模。它们不是公开包内的记录数，也不是本次中性分类规则重新处理后的统计。公开项目只能直接复现 19 条合成资料与 48 个开发回归场景的结果。

## 接入约定

产品和客户端分类使用可编辑的中性示例规则。渠道消息统一映射为 `message_id`，避免代码依赖特定消息平台字段。接入真实数据时，需重新配置分类、脱敏、核查来源及有效期，再独立评测。

仅保留模型 API 接入所需的 provider 值、环境变量和默认 API 域名。默认 `local` 模式不发起模型请求。项目名称、演示回答和示例知识不使用厂商身份。
