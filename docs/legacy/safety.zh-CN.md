# 早期 RAG 回答策略

[旧版入口](README.zh-CN.md) · [English](safety.md)

本页描述独立 RAG。当前网站另有受权限控制的业务工具和审批流程。

问题及检索文本都视为不可信数据，不执行其中夹带的指令，不索要密码、API Key 或完整支付凭证。

客户证据可包含有效期内的 `customer_safe` P1 知识，以及无规则冲突的 P2 排障线索。受限资料、内部正文、过期资料及冲突案例排除。引用元数据来自提供的记录，但不构成逐句事实检查。

| 情况 | 旧入口行为 |
|---|---|
| 证据不足 | 询问相关细节 |
| 账户操作或当前服务状态 | 升级核验，未连接业务工具 |
| 模型接口失败 | 向接入层返回错误 |
| 内部 / 受限正文 | 不进入客户证据 |

升级不会创建工单。独立网页没有鉴权，仅用于本地演示。[当前网站](../architecture.zh-CN.md)有不同的权限和回退机制。

私有目录是否忽略以 `.gitignore`、`.dockerignore` 为准，不能假设整个 `knowledge/official/` 都被排除。[数据范围](data_scope.zh-CN.md)。
