## 消息可见范围

| 内容 | 客户 | 客服 | 管理工作台 |
|---|---|---|---|
| 已发布最终回复、模型与来源标记 | 可见 | 可见 | 可见 |
| 尚未发送的最终草稿、发送及撤回按钮 | 不可见 | 可见 | 可见 |
| 知识 ID、检索分数、查询链路及依据说明 | 不可见 | 不可见 | 可见 |
| 回正成功及当前余额内部回执 | 不可见 | 可见 | 可见 |
| 模型用量及费用单价设置 | 不可见 | 不可见 | 可见 |

管理员切到个人视图也失去工作台访问权限。接口先过滤私有消息和运行详情，再返回数据；工单预览只取公开内容。SSE 仅通知版本变化，各端重新读取自己有权查看的数据。

## 查看答复依据

用 `admin@lumen.test` 打开工单。最终回复前会有一条简短内部消息，说明分诊与路由、`ERR-401`＋`PLAN-001` 等依据、BM25 / 字符权重、实际查询工具、质检及回复来源。

真实模型在同一次结构化生成中先输出 `evidence_summary`，再输出 `answer`；程序补充真实执行记录，并剔除引用未命中知识 ID 的摘要。这是可核查的证据说明，不是模型隐藏思维过程。会增加少量输出 Token，但**不单独增加模型调用**。本地模式、财务固定模板和回退使用程序生成的记录，不冒称模型分析。

内部消息不进入后续公开对话上下文。客服若编辑最终草稿，原依据仍描述生成时的记录，不代表重新分析了编辑后的文本。

回执分别标注真实模型答复、财务固定模板和实际回退。真实模型分诊成功后使用事务模板，不等于模型失败。[真实验收示例](live-model-acceptance.zh-CN.md)。

## 回正命令

客服或管理员在工单回复框单独输入 `/recharge`，可跳过回正资格条件，将当前客户的负余额归零。不能带金额、给正余额充值或指定其他账户。事务提交后的结果仅内部显示；客户账户余额实时更新，不收到命令或成功回执。

自动回正仍须有明确诉求、来源与账本核验、$5 / 7 天资格及自动发送权限。人工介入或关闭自动发送时保留草稿，不提前承诺操作成功。

## 用量与费用

管理员打开 **工作流设置**：查看已保存工单调用的失败、重试、输入 / 输出 Token 和模型阶段累计耗时。**不包含启动时的 3 次连接检测**；累计 API 耗时也不是客户等待时间。

自行填写服务商每百万输入 / 输出 Token 单价和三字母币种。优先匹配响应模型名，其次匹配配置的模型 ID。没有对应价格或服务商未返回用量时，费用显示不完整；失败调用若返回用量也会计入，不猜测价格。

总览按当前保存的单价重算，不单独处理缓存折扣、历史调价、税费或最低收费，不等于服务商账单。单价保存在本地普通设置中，API Key 仍仅留在进程内；当前不声称已实现具体成本节省。
